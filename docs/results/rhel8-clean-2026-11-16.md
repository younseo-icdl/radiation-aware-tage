## Conditions and metrics

Each workload uses the same executable and input across seven configurations. The system is one X86O3CPU at 2 GHz, with the decoupled frontend disabled, 32 KiB two-way L1 instruction/data caches with two-cycle latencies, and 256 MiB DDR3_1600_8x8 memory. TAGE geometry and training parameters are unchanged; minHist=5, maxHist=130, speculative history enabled. The four recurrent baselines share S*=346 bits. Periodic parity and exact direct folding are additional comparisons.

All finite cells use query L=1, update L=1, query/update II=1, no early-unconditional variant, and no fault schedule. The native reference is the instrumented backend's ordinary timing path, rather than a separate pristine upstream build. Completed cells are audited for matching CPU/cache/memory/Process parameters and TAGE geometry. Working-directory aliases created during consolidation are resolved to the same physical directory for that audit.

Cycles are `system.cpu.numCycles` at architectural program exit; instructions are `simInsts`, and IPC is instructions/cycles, checked against the reported IPC. Finite statistics are frozen before helper observation. Positive overhead means more cycles: `100 * (cycles/reference_cycles - 1)`. Report common finite-path overhead against native and additional protection overhead against finite P0 separately. Host elapsed execution time is not simulated CPU performance.

There is one deterministic clean measurement per cell, with seed 548. No confidence interval or workload fault campaign is claimed. Equal clean cycles under fixed modeled stage latencies do not establish equal hardware area, power, or delay. RTL, Cadence, and PPA work are outside this comparison.

## Artifacts and reproduction

The first-attempt audit is `work/destination-clean-2026-11-16/results-parallel.json` (CSV and Markdown siblings are available). It reconciles the original four-worker collector and twelve additional workers into exactly one actual execution per cell. Sixteen duplicate admission attempts were skipped before simulator launch; these scheduling skips are not workload failures. Both collector outputs are retained for audit.

Per-cell artifacts are `<root>/<program>/<configuration>/`; simulator logs are `<root>/<program>/<configuration>.log`. The first root is `work/destination-clean-2026-11-16`; the retry root is `work/destination-clean-2026-11-16-retry`. Each successful finite run retains `seu.program_exit.json`, `seu.json`, `termination.json`, `config.json`, `stats.txt`, stdout, and stderr. Runtime counters include accepted/consumed/cancelled requests, outstanding maxima, and source/dependency/queue/response stalls. Stall totals are not an additive CPI decomposition.
