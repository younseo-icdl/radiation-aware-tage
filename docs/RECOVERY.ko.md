# 복구 범위와 근거

2026-11-05 현재 원래 `ele548-project*` 작업 폴더와 마지막 결과 ZIP은 사라졌습니다. 남아 있는 사용자 첨부자료와 과거 도구 기록을 바탕으로 소스를 회수했습니다.

1. 원래 첨부 ZIP/논문/문서는 별도의 private 복구 ZIP에 원본 bytes와 SHA256로 보존했습니다.
2. `recovered/`는 기록된 Add File와 문맥이 정확히 맞는 Update File 요청에서 추출한 파일 후보입니다. 요청 기록만으로 실제 당시 실행 성공을 증명하지 않습니다.
3. `recovered_static/`는 원본 명령을 실행하지 않고, 메모리 안의 가상 파일에 한정해 문자 그대로의 파일 생성·복사·문자열 수정·확정 가능한 patch를 연결한 결과입니다. 컴파일/실험/외부 명령은 실행하지 않았습니다. 복구할 수 없는 입력과 연산은 건너뛰었습니다.
4. 마지막 B4 namespace에 도달한 후보를 `final_b4/`에 따로 정리합니다. 원본 절대경로와 후보의 SHA256를 함께 기록합니다. 누락된 dependency나 원래 source-lock 전체가 자동으로 복원되었다는 뜻은 아닙니다.
5. 원문 도구 출력에 실제로 인쇄된 SHA256를 찾을 수 있는 경우에만 파일 bytes를 비교했습니다. 결과는 `recovery/HISTORICAL_HASH_COMPARISON.csv`입니다. 해시가 없는 파일에 대해 원본과 동일하다고 주장하지 않습니다.

독립 평가 요약42행은 과거 출력에서 회수했습니다. 출력 당시 평균 net%A는 소수6자리로 인쇄되어 그 정밀도를 보존합니다. 원래510개 A/B/C/D 행, 원시 주입 기록, config/ELF의 완전한 집합을 이 표에서 역산하거나 만들어 내지 않습니다. 기존 최종ZIP의 당시 SHA256는 `2601011485402c67bf4bfbba5652cb5567d49356db382eee930162642e9002ea`였지만 해당 ZIP 자체를 되찾은 것은 아닙니다.

이전 문서에 있는 PASS는 당시 실험의 보고입니다. 복구 후 소스가 같은 실험을 재현한다는 새로운 PASS가 아닙니다. 현재 사용자 요청에 따라 기존 실험을 재실행하지 않았습니다.
