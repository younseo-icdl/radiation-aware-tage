# 현재 필요한 사용자 행동

이번 C++ 구현·gate·부품 실험을 위해 추가 compiler/library/license/path/dataset은 필요하지 않았다. 실제 build/test command는 모두 exit0이며 metadata의 uncorrectable fixture는 의도한 fail-closed exception으로 별도 검증했다. 이를 전체 프로그램 성공으로 분류하지 않았다.

현재 추가 실행 승인을 요청하지 않는다. 승인한 CPU 상한3487회는 이전 v11에서 모두 사용했고 이번 CPU는0회다. 다음에는 source queue4칸이 실제 BPU squash의 여러 callback을 lossless하게 받을 수 있도록 packet/credit를 연결하고, PC/context·보호 controller를 실제 gem5 producer에 연결해야 한다. 아직 준비되지 않은 producer를 실행하거나 임의의 새 CPU 수를 요청하지 않는다.

`inverse_jump.hpp`는 큰 undo를 공정한 recurrent baseline으로 처리할 수 있는 정확성 근거이며 아직 그 stage 구현은 아니다. 구현·정확성·새 manifest를 구체화한 뒤 필요한 native/O3 pilot 수와 시간/저장량을 산정한다. 현재 source/controller 작업과 검토는 남은 preparation 예산에서 계속할 수 있다. RTL/Cadence/SPICE/TCAD는 실행하지 않는다.
